# paper/

- `main.tex`: ACM Computing Surveys manuscript (acmart, `manuscript,screen,review`).
- `main_tmlr.tex`: TMLR fallback (needs `tmlr.sty` uploaded to Overleaf).
- `sections/`: one file per section; both root documents include the same files.
- `references/must_cite.bib`: seed bibliography. Better BibTeX will also keep `references/harness-review.bib` updated from the Zotero group; switch `\bibliography{}` to it once that export exists.
- `figures/`: generated by `scripts/analysis/figures.py` (`make figures`). Do not hand-edit.

Overleaf: New Project > Import from GitHub > this repo; set `main.tex` as root. Overleaf's TeX Live ships acmart.
