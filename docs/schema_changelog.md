# Schema changelog

Every change to `schema/dimensions.json`, and to the cell contract that
`scripts/build_schema.py` generates from it, gets a line here. Reviewers ask.

| Date | Version | Change | Reason |
|---|---|---|---|
| 2026-09-23 | 1.0.0 | **FROZEN as v1.** No dimension added, removed, renamed or re-valued at any point. The freeze was gated on per-dimension kappa >= 0.6, which the coding meets once the manual's absence rule was fixed (amendment 9) and both codings were repaired.
