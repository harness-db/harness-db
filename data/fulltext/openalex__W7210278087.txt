Abstract

Verification of Electronic Design Automation (EDA) tools requires large test suites written in hardware description languages (HDLs) such as VHDL and SystemVerilog. Creating such tests is labor-intensive because engineers must reason about feature specifications, HDL syntax and version rules, and tool execution flows. A human-in-the-loop agentic framework is introduced for automated test creation for EDA tool verification. The framework combines a large language model (LLM) agent with tool access through the Model Context Protocol (MCP) and structures generation into planning, generation, and validation phases, incorporating requirement analysis, domain knowledge injection, repository-aware template learning, constrained test generation, and execution-based iterative repair. Human confirmation gates between phases enable engineers to review intermediate artifacts while maintaining control over the workflow. In an industrial evaluation across six verification domains and 18 feature specifications and test plans, the framework generated an estimated 95–150 tests, reduced end-to-end QA engineering effort by about 40% on average, and achieved a validated effective-test rate of approximately 70%. The generated test suites also contributed to improved behavioral coverage and the discovery of previously untested scenarios in EDA tool verification.
